# Static resume website

A static HTML, CSS and JavaScript resume and portfolio site for GitHub Pages.

## Publish manually

1. Create a public repository named `Echo-Tian1.github.io` under the `Echo-Tian1` account.
2. Upload the contents of this directory to the root of the repository, including `.nojekyll`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then save.
6. Wait for GitHub Pages to finish publishing and verify the site at `https://echo-tian1.github.io/`.

No package installation or build step is required. The repository owner or an account with repository administration permissions must create the repository and enable Pages.
